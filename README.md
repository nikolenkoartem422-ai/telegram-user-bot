# Telegram Info Bot

Информационный Telegram-бот на Python и aiogram 3.

## Возможности

- Приветствие пользователей
- Главное меню
- Раздел «О боте»
- Раздел «Информация»
- Раздел «Поддержка»

## Установка

pip install -r requirements.txt

## Настройка

Создай файл .env и добавь:

BOT_TOKEN=твой_токен

## Запуск

python main.py
